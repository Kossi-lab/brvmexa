Vos questions

Quelle version choisir ?

La version numérique (Chariow) se télécharge tout de suite en PDF et se lit sur téléphone, tablette ou ordinateur. La version papier (Amazon) est un livre broché imprimé, livré chez vous, idéal pour l’annoter et le garder dans votre bibliothèque.

Comment je reçois la version PDF ?

Juste après l’achat sur Chariow, vous recevez le fichier PDF à télécharger. Vous pouvez le lire hors connexion.

Le livre est-il adapté si je n’y connais rien ?

Oui. C’est un guide pratique, pensé pour vous accompagner dès vos premiers pas à la BRVM.

Le livre remplace-t-il un conseiller ?

Non. C’est un guide de formation : il vous apprend une méthode, mais chaque décision d’investissement reste la vôtre. Pour acheter des titres, passez par une SGI agréée.
